Tentang Project

Project ini dibuat menggunakan framework Laravel.

Persyaratan
PHP
Composer
Node.js dan NPM
Database MySQL/MariaDB
Cara Menjalankan Project
Clone atau download repository.
Jalankan composer install.
Salin .env.example menjadi .env.
Atur konfigurasi database di file .env.
Jalankan php artisan key:generate.
Jalankan migrasi database jika diperlukan dengan php artisan migrate.
Jalankan npm install dan npm run build jika project menggunakan Vite.
Jalankan aplikasi dengan php artisan serve.
